These three-frame fixtures reproduce Chromium issue 532860177 without using
third-party footage. They contain FFmpeg-generated SMPTE bars at 854x480.
The reference files copy the same encoded picture data and add explicit BT.601
SPS/VUI signaling using FFmpeg's h264_metadata bitstream filter. They are hosted
at https://remotion.media/mediabunny-h264-color-space-v1/; do not commit the MP4s.

Generate from the repository root (FFmpeg 7.1 with libx264):

ffmpeg -f lavfi -i smptebars=size=854x480:rate=30 \
  -vf setparams=range=unknown:color_primaries=unknown:color_trc=unknown:colorspace=unknown \
  -frames:v 3 -c:v libx264 -bf 0 -g 60 -pix_fmt yuv420p -an /tmp/untagged-h264.mp4

ffmpeg -i /tmp/untagged-h264.mp4 -c:v copy \
  -bsf:v h264_metadata=video_full_range_flag=0:colour_primaries=6:transfer_characteristics=6:matrix_coefficients=6 \
  /tmp/bt601-h264.mp4

ffmpeg -i /tmp/untagged-h264.mp4 -c:v copy \
  -bsf:v h264_metadata=video_full_range_flag=1:colour_primaries=6:transfer_characteristics=6:matrix_coefficients=6 \
  /tmp/bt601-full-range-h264.mp4
